# VidaFit 

VidaFit es un proyecto de comercio electronico enfocado en el sector fitness y bienestar humano, desarrollado como un proyecto academico del programa para desarrolladores junior fullStack de Generations colombia.

La plataforma permite a los usuarios explorar un catalogo de productos relacionados con el entrenamimetnso y la nutricion deportiva, aplicar filtros y diferentes opciones de ordenamiento, visualizar los productos disponibles de la marca y gestinar sus compras mediantes un carrito interactivo.

El proyecto busca integrar una interfaz moderna, intuitiva y responsive con funcionalidades dinamicas desarrolladas con HTML:5 y js para buscar la mejor experiencia de usuario posible.

## Funcionalidades Principales

 - 📦 Catálogo de productos fitness y suplementos.
 - 🔎 Filtrado por categoría, marca, precio y disponibilidad.
 - ↕️ Ordenamiento por precio, ventas y valoración.
 - 🖼️ Vista de productos en cuadrícula y lista.
 - ❤️ Sistema de favoritos.
 - 🛒 Carrito de compras interactivo.
 - ➕➖ Control de cantidades de productos.
 - 💰 Cálculo automático de subtotales y total de compra.
 - 📱 Diseño responsive para diferentes dispositivos.
 - 🧭 Navegación entre las diferentes secciones del sitio.
 - 📞 Sección de contacto y presentación de la empresa.
